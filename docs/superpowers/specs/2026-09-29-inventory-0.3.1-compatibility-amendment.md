# Inventory 0.3.1 — Joomla 6 Compatibility Amendment

This amendment supersedes the Joomla 5/6 compatibility assumption in the Inventory 0.3.0 design and implementation plan.

## Release identity

Inventory 0.3.0 was produced as a test artifact. Because a different artifact must never reuse the same version number, the Joomla-6-only correction is released as Inventory 0.3.1.

## Supported platform

- Joomla 6 only.
- Runtime verification baseline: Joomla 6.1.3.
- PHP minimum: 8.3.0, matching Joomla 6 minimum requirements.
- CI compatibility matrix: PHP 8.3 and PHP 8.4.
- Joomla 5 is not declared, tested, or supported by Inventory 0.3.1.

## Scope

No Inventory domain behavior changes from the approved 0.3 functional baseline. Dashboard, Items, Movements, ACL, CSRF, transactional stock integrity, responsive UI, language support and database ownership rules remain unchanged.

## Database

0.3.1 is non-destructive and introduces no schema changes. `0.3.1.sql` exists only as a versioned schema marker so Joomla can track the update level consistently.
